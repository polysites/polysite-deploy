# Security policy

Security reports for this repository follow the core repository's policy: [SECURITY.md](https://github.com/polysites/polysite/blob/main/SECURITY.md).

**Please do not open a public issue.** The preferred channel is GitHub's private vulnerability reporting: use the
**Security** tab of this repository, then **Report a vulnerability**.
If that is unavailable, the fallback contact is **info@quicksupporttoday.com**.
