# Contributing

Contributions to this repository follow the core repository's guide, including the conventions and the contribution terms:
[CONTRIBUTING.md](https://github.com/polysites/polysite/blob/main/CONTRIBUTING.md). The tests in this repository need a checkout of the core next to it
(`POLYSITE_CORE`, see the README): run `sh kubernetes/test/lint.sh` and `sh templates/test.sh static` before you open a pull request.

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
